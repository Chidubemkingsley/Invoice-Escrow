# Contract interfaces — exact signatures

Generated from the deployed ABIs in this folder.

- `USDG.json` — pulled from the Blockscout API for the **verified** USDG implementation (`is_verified: true`), byte-identical on Arbitrum Sepolia and Robinhood Chain Testnet.
- `InvoiceEscrow.json`, `AdvancePool.json` — extracted from the Foundry artifacts of the sources verified on both explorers.

The custom errors below are what the contracts revert with; decode them in the UI to explain a failed transaction instead of printing a raw selector. Enums appear as their underlying integer type, which is what the ABI encodes.
